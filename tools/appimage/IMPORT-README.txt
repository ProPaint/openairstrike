OpenAirStrike: put your own game files here
===========================================

OpenAirStrike plays AirStrike 3D (1.70), AirStrike 2 (2.51) and AirStrike II: Gulf Thunder
(2.71) with the files of your own copy of each game. No game file comes with it.

Copy into this folder, for each game you own, one of:

  - the game's install folder from a Windows PC (the folder holding the game's .exe and its
    "data" folder with pak0.apk, pak1.apk, ...), copied whole;
  - the game as you downloaded it: a zip, RAR or 7z archive, or its setup .exe (an Inno Setup
    installer; NSIS and Gentee installers are refused: install those on a PC first and copy
    the install folder).

Then start OpenAirStrike. At each start it installs what is new in this folder (it can take a
minute for an archive), then opens the game. With more than one game it opens on a game
selector. The files here are only read: you can delete them once the game has started.

If nothing is recognised, the game says so on screen with what the importer found.
